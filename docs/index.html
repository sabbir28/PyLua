Introduction to PyLua

PyLua is a next-generation programming language built directly on an optimized Lua core (v5.5.1). Designed for game developers, tool creators, and software engineers who desire the rapid execution and lightweight footprint of Lua without the syntax quirks (such as mandatory then ... end blocks, unexpected global variable leaks, and missing math primitives).

Whether you are building cross-platform 2D desktop games, scripting automation tools, or embedding a fast scripting language into an application, PyLua gives you an expressive syntax with batteries included.

Installation & Setup

PyLua is distributed as a single standalone executable and as an installable package for Windows, Linux, and Android.

Windows (Installer or Standalone)

Download the latest PyLua-Setup.exe from the Releases page. The installer registers pylua.exe in your system PATH and installs all runtime dependencies including GLFW.

PowerShell
# Verify your installation
pylua -v
# Output: Lua 5.5.1  The LEngine

Building from Source (CMake + Ninja)

PyLua builds with CMake 3.20+ and any standard C99 compiler (MSVC on Windows, GCC/Clang on Linux):

Bash / PowerShell
git clone https://github.com/sabbir28/PyLua.git
cd PyLua
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel

Quickstart Tutorial

Create a file named main.lua and run it with pylua main.lua:

PyLua
-- main.lua
import os
import engine

print("Welcome to PyLua!")

-- Variable assignment is auto-local!
score = 100
playerName = "Hero"

-- C-style conditional with parentheses and braces
if (score >= 100) {
    print(playerName .. " leveled up!")
} else {
    print("Keep training...")
}

Python-Style import

Instead of declaring local variables and calling require() repeatedly, PyLua introduces the top-level import keyword:

PyLua
import engine
import os
import vector

-- Equivalent to:
-- local engine = require("engine")
-- local os = require("os")
-- local vector = require("vector")
💡 Standard require() Compatibility

Traditional local mylib = require("mylib") remains 100% functional and compatible.

C-Style Curly Braces & Conditionals

PyLua supports curly braces { ... } for blocks and optional parentheses around conditional expressions. You can freely use if (cond) { ... } elseif (cond) { ... } else { ... }:

PyLua
speed = 45

if (speed > 60) {
    print("Too fast!")
} elseif (speed == 45) {
    print("Cruising speed.")
} else {
    print("Too slow.")
}

Braced Function Declarations

Anonymous and table-member functions can use curly braces function(args) { ... }:

PyLua
-- Callback with curly braces
onPlayerHit = function(damage) {
    health = health - damage
    return health > 0
}

-- Table method definition
player = {
    x = 10,
    y = 20,
    move = function(self, dx, dy) {
        self.x = self.x + dx
        self.y = self.y + dy
    }
}

Auto-Local Variable Scoping

One of the biggest pitfalls in standard Lua is accidentally forgetting the local keyword, causing variables to leak into the global environment _G.

In PyLua, assigning to an undeclared identifier automatically declares it in the current local scope:

PyLua
function calculateArea(width, height) {
    area = width * height  -- Automatically scoped locally!
    return area
}

calculateArea(5, 10)
print(area)  -- Output: nil (does not leak to global scope!)
Explicit Globals

To explicitly create or modify a global variable from inside a function, assign directly to _G.myVar = value.

Idiomatic PyLua Coding Style Guide

Follow these community guidelines for writing clean, maintainable PyLua code:

  • Imports: Place all import statements at the very top of each file.
  • Naming:
    • camelCase for variables and function names (playerSpeed, getDeltaTime()).
    • PascalCase for Screen tables, Entities, and Metatables (GameScreen, MenuScreen).
    • UPPER_SNAKE_CASE for constants (MAX_ENTITIES = 1024).
  • Braces: Use 1TBS (One True Brace Style) with opening braces on the same line: if (cond) {.
  • Parentheses: Enclose conditional expressions in parentheses for clarity: if (player.isAlive) { ... }.

PyLua 2D Game Engine Architecture

The PyLua Game Engine is an integrated, hardware-accelerated 2D game framework inspired by Unity and LÖVE2D. It features a complete game loop, physics integration, immediate-mode rendering, and threaded workers.

The Main Game Loop: engine.run(config)

The engine handles window polling, physics simulation, entity script updates, and frame rendering automatically:

PyLua
import engine

win = engine.Window.create("My Game", 1280, 720)

engine.run({
    window = win,
    
    init = function() {
        print("Game initialized!")
    },
    
    update = function(dt) {
        -- Runs every frame. dt is delta time in seconds.
        if (engine.Input.isKeyJustPressed("escape")) {
            engine.stop()
        }
    },
    
    draw = function() {
        engine.Graphics.clear(0.1, 0.1, 0.15, 1.0)
        engine.Graphics.drawText("Running PyLua 2D", 20, 20)
    }
})

Physics & Collisions (engine.Physics)

Create 2D physics worlds, static obstacles, and dynamic bodies:

PyLua

world = engine.Physics.createWorld(0, -980)

-- Add static ground: (type=0: static, x, y)
ground = world:addBody(0, 400, 50)
ground:setRect(800, 20)

-- Add dynamic ball: (type=1: dynamic, x, y)
ball = world:addBody(1, 400, 500)
ball:setCircle(25)
ball:setVelocity(100, 0)

-- Step physics in update
world:step(dt)
x, y = ball:getPosition()

Scene & Entity System (engine.Scene)

Attach multiple modular scripts to game entities. The engine automatically updates them every frame:

PyLua
player = engine.Scene.createEntity("Player")

-- Movement component
movementScript = {
    update = function(self, dt) {
        if (engine.Input.isKeyDown("d")) {
            print("Moving right...")
        }
    }
}

-- Health component
healthScript = {
    hp = 100,
    update = function(self, dt) {
        if (self.hp <= 0) {
            player:destroy()
        }
    }
}

player:addScript(movementScript)
player:addScript(healthScript)

Complete Game Example: Snake XL

A full snake game demonstrating Screen management, immediate UI, input, and graphics:

snake.lua
import engine

win = engine.Window.create("PyLua Snake", 640, 640)
GRID = 20

GameScreen = {
    onEnter = function(self) {
        self.snake = {{x=10, y=10}, {x=10, y=11}}
        self.dir = {x=0, y=-1}
        self.food = {x=5, y=5}
        self.score = 0
        self.timer = 0
    },
    
    update = function(self, dt) {
        if (engine.Input.isKeyJustPressed("w")) { self.dir = {x=0, y=-1} }
        if (engine.Input.isKeyJustPressed("s")) { self.dir = {x=0, y=1} }
        if (engine.Input.isKeyJustPressed("a")) { self.dir = {x=-1, y=0} }
        if (engine.Input.isKeyJustPressed("d")) { self.dir = {x=1, y=0} }
        
        self.timer = self.timer + dt
        if (self.timer >= 0.15) {
            self.timer = 0
            head = {x = self.snake[1].x + self.dir.x, y = self.snake[1].y + self.dir.y}
            table.insert(self.snake, 1, head)
            
            if (head.x == self.food.x && head.y == self.food.y) {
                self.score = self.score + 10
                self.food = {x = math.random(0, GRID-1), y = math.random(0, GRID-1)}
            } else {
                table.remove(self.snake)
            }
        }
    },
    
    draw = function(self) {
        engine.Graphics.clear(0.08, 0.08, 0.12, 1.0)
        
        -- Draw Food
        engine.Graphics.drawRect(self.food.x * 32, self.food.y * 32, 30, 30, 1.0, 0.2, 0.2, 1.0)
        
        -- Draw Snake
        for _, part in ipairs(self.snake) {
            engine.Graphics.drawRect(part.x * 32, part.y * 32, 30, 30, 0.2, 0.8, 0.4, 1.0)
        }
        
        engine.Graphics.drawText("Score: " .. self.score, 10, 10, 2.0)
    }
}

engine.Screen.set(GameScreen)
engine.run({ window = win })
