Entity-Script Component Architecture (`engine.Entity`)

Build modular game worlds using Unity-style entity components. Entities represent scene objects while attached scripts encapsulate behavior, rendering, and lifecycle dispatch.

1. The Entity Lifecycle

Every script table attached to an entity can implement four optional lifecycle methods called automatically by engine.run(): 

┌─────────────────────────────────┐
│       script:init(entity)       │ ──▶ Called once when script is attached
└────────────────┬────────────────┘
                 │
                 ▼
┌─────────────────────────────────┐
│     script:update(entity, dt)   │ ──▶ Called every frame with delta time dt
└────────────────┬────────────────┘
                 │
                 ▼
┌─────────────────────────────────┐
│       script:draw(entity)       │ ──▶ Called every frame during render pass
└────────────────┬────────────────┘
                 │
                 ▼
┌─────────────────────────────────┐
│    script:onDestroy(entity)     │ ──▶ Called when entity is removed from the scene
└─────────────────────────────────┘

2. Creating Component Scripts

turret_component.lua
import engine

-- Define reusable Turret script component:
TurretScript = {
    fireTimer = 0,
    fireRate = 0.5 -- Seconds between shots
}

function TurretScript:init(entity) {
    entity.x = 200
    entity.y = 300
    print("[Turret] Deployed at " .. entity.x .. "," .. entity.y)
}

function TurretScript:update(entity, dt) {
    self.fireTimer = self.fireTimer + dt
    if (self.fireTimer >= self.fireRate) {
        self.fireTimer = 0
        print("[Turret] Fire projectile!")
        engine.Audio.playSound("assets/laser.wav")
    }
}

function TurretScript:draw(entity) {
    engine.Graphics.drawRect(entity.x, entity.y, 32, 32, 1.0, 0.4, 0.1, 1.0)
}

-- Spawning entity and mounting component:
turretEntity = engine.Entity.create("DefenseTurret_01")
turretEntity:attachScript(TurretScript)
