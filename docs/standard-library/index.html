Standard Library Overview

PyLua ships "batteries included". In addition to standard Lua libraries, it bundles built-in 2D/3D vectors, asynchronous HTTP networking, native OS GUI windows, and cryptographic hashing.

Built-in Standard Library Suite

Core

Base Built-ins

Fundamental functions available globally: print, assert, pcall, xpcall, type, and tostring.

 Math & Physics

Vector Library

Native vector.Vector2 and Vector3 types with operator overloading, dot products, cross products, and normalization.

 Text Processing

String & UTF-8

Pattern matching, regex-like capture extraction, binary buffers, and full Unicode UTF-8 codepoints.

 Data Structures

Table Manipulation

High-speed array operations, sorting, packing, unpacking, element insertion, and deletion.

 Numeric

Math Library

Trigonometric functions, random number generation, IEEE 754 constants, integer division, and bitwise math.

 System

I/O & Operating System

File stream read/write, process execution, environment variables, clocks, and filesystem manipulation.

 Networking

HTTP Networking

REST API client with request.get() and request.post(), headers, and automatic JSON response parsing.

 Desktop UI

Native GUI Subsystem

Create native Windows dialogs, buttons, text fields, and message boxes with zero external GUI dependencies.

 Security

Cryptography & Hash

Generate cryptographic digests with MD5 and SHA-256 for data verification, hashing, and passwords.
