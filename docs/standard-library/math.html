Math & Numeric Functions (`math`)

The math module provides standard mathematical, trigonometric, rounding, and cryptographic-grade xoshiro256** pseudo-random number generator functions.

Trigonometry & Angles

Function Signature Description
math.sin(x) (num) → num Sine of angle x in radians.
math.cos(x) (num) → num Cosine of angle x in radians.
math.tan(x) (num) → num Tangent of angle x in radians.
math.atan(y, [x]) (num, [num]) → num Arc tangent of y/x in radians, using signs to find quadrant.
math.deg(x) (num) → num Converts angle x from radians to degrees.
math.rad(x) (num) → num Converts angle x from degrees to radians.

Rounding & Constants

Identifier Value / Behavior
math.floor(x) Largest integer less than or equal to x.
math.ceil(x) Smallest integer greater than or equal to x.
math.abs(x) Absolute value of x (preserves integer type if integer).
math.sqrt(x) Square root \(\sqrt{x}\).
math.pi Mathematical constant \(\pi \approx 3.14159265358979323846\).
math.huge IEEE 754 positive infinity (\(+\infty\)).
math.maxinteger Maximum 64-bit signed integer: 9223372036854775807 (0x7FFFFFFFFFFFFFFF).
math.mininteger Minimum 64-bit signed integer: -9223372036854775808 (-0x8000000000000000).

Pseudo-Random Number Generator

random_numbers.lua
-- Seed the xoshiro256** generator with current OS timestamp:
math.randomseed(os.time())

-- Uniform float in range [0.0, 1.0):
val = math.random()

-- Uniform integer in range [1, 6] (Dice roll):
die = math.random(1, 6)

-- Uniform integer in range [100, 500]:
gold = math.random(100, 500)
